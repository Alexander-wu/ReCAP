# Paper figures

These images are copied without modification from the supplied ReCAP manuscript source, *Efficient Training-Free Context Scheduling for Long-Horizon Robot Video World Models*.

| Release asset | Manuscript source | LaTeX location |
| :--- | :--- | :--- |

The method figure illustrates anchor preservation, recent-block retention and stale-history eviction. The teaser reports the paper's dedicated attention, BridgeV2, VLM and memory studies. Its panels use dedicated samples and extrapolation horizons; they are not directly comparable to every fixed-horizon reference experiment in this repository.

The images present manuscript results, not new release-validation measurements. The released ~127M models and archived reference experiments cover a subset of the paper; see [coverage](../COVERAGE.md). No plot values or labels were redrawn. Exact source/release hashes are recorded in [`SOURCE_PROVENANCE.json`](../../SOURCE_PROVENANCE.json).
